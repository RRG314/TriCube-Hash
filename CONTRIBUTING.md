# Contributing

TriCube needs careful review more than feature growth. Useful contributions
include reproducible test results, reduced-round analysis, differential or
rotational probes, clear performance measurements, portability fixes, and
comparison against mature hash and XOF designs.

Please keep claims narrow:

- Do not describe TriCube as secure.
- Do not infer cryptographic strength from statistical batteries alone.
- Include exact commands, platform details, input sizes, seeds, and logs for new
  results.
- Keep generated artifacts out of pull requests unless they are small,
  interpreted, and needed for reproduction.

This work received no external funding.
