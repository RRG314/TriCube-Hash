# Security Policy

TriCube is experimental research software. Do not use it for passwords, digital
signatures, message authentication, key derivation, consensus systems, encrypted
storage, production random streams, or any other security-critical purpose.

No independent cryptanalysis has been completed. No collision-resistance,
preimage-resistance, second-preimage-resistance, indifferentiability, or
pseudorandomness proof is claimed.

Cryptanalytic findings, structural weaknesses, reproducible failures, and test
results are welcome through GitHub issues at:

https://github.com/RRG314/tricube-hash/issues

There is no formal bounty or coordinated disclosure program for this research
prototype.
